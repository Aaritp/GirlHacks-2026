# Demo planning

The ADP challenge asks for a **5-minute** demo; the team architecture mentions 3 minutes.
Prepare a 3-minute core flow plus 2 minutes explaining value and architecture.

Start with the fictional customer-onboarding conversation in `web/src/api/fixtures.ts`.
Show speech → transcript → traceable commitment → forest, then a head-only user
composing, confirming and speaking a response. Show whiteboard/roots only once core
flows work. Rehearse live services and record a backup; identify prerecorded or mocked
segments honestly. Browser mocks are development fixtures, not AI output.
